Vitrine de produtos desenvolvida em **React + TypeScript**, com estilização em **Sass**, conforme o layout fornecido no Figma e o teste técnico da Econverse.

- Vitrine de produtos consumindo dados de um arquivo JSON
- Modal de produto com as principais informações (nome, preço, descrição, quantidade e botão de compra)
- Layout fiel ao Figma, pixel a pixel
- HTML semântico e boas práticas de SEO

# Tecnologias utilizadas
- [React](https://react.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [Vite](https://vitejs.dev/)
- [Sass](https://sass-lang.com/)
- [ESLint](https://eslint.org/)
- [Vitest](https://vitest.dev/) para testes unitários

## ▶️ Como rodar o projeto?
# Passo a passo
1. Clone o repositório:
   ```bash
   git clone https://github.com/SEU-USUARIO/NOME-DO-REPO.git
   cd NOME-DO-REPO
   ```

2. Instale as dependências:
   ```bash
   npm install
   ```

3. Rode o projeto em modo de desenvolvimento:
   ```bash
   npm run dev
   ```

4. Acesse no navegador:
   ```
   http://localhost:5173
   ```

- O projeto não utiliza bibliotecas de UI (Bootstrap, Foundation, etc.), conforme solicitado no teste.
- A estilização foi feita inteiramente com Sass, seguindo o layout do Figma pixel a pixel.
